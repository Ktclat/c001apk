## 本轮修改

现有字体资源和默认排版已经符合需求：界面使用内置 `C001NotoSans` 三字重，正文默认舒适阅读；首次字体迁移后保留用户后续选择。本轮保留这些实现，并把界面字体、正文排版与字号整理到独立的“阅读与字体”。颜色、主题与悬浮导航位于“外观与导航”。

原悬浮导航开启后总是随滚动隐藏，没有独立选择。本轮新增“滚动时隐藏悬浮导航”，默认开启并独立持久化。关闭时立即恢复导航，后续滚动保持显示；开启时沿用现有平滑下移动画和反向恢复。切换开关清除旧滚动会话，防止之前手势的惯性尾段立即再次隐藏。输入法隐藏、点击与无障碍恢复、底部内容和 FAB 避让继续沿用现有逻辑。

## 上游差异与同步边界

最新上游相对之前审计的 `851ad81` 有两个提交，比较包含 134 个文件；涵盖内容过滤、新手引导、媒体加载、导航外观、公告及设备身份显式获取。最新设备身份服务的 `ensure()` / `beforeRequest()` 已为空实现，注册由用户操作触发，不能沿用旧审计中“启动自动注册”的结论。

本轮已拉取并审阅最新源码，交付上述阅读与导航需求，**没有把全部 1.5.0 功能合入本仓库**。后续完整整合需要适配账号会话隔离、手动设备导入、受限 Markdown 解析、媒体重试、本仓库导航及独立发行身份；不能用整套上游覆盖。上游的公开 basic 后端可独立构建，私有扩展锁文件不构成公开构建的凭据要求。
