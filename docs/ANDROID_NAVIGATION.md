# Android 悬浮 Tab 导航

本分支提供一个可选的**悬浮底部 Tab 栏**，保持已有导航信息架构。

## 使用

在 **我的 → 设置 → 外观与字体 → 悬浮 Tab 导航** 打开开关。
启用后，主页／关注／我的三个底部入口显示为带阴影和圆角的 Material 3 胶囊栏；关闭即恢复传统底栏。
默认关闭，已有用户不会在升级后突然改变操作方式。该设置持久保存在 Hive 的 `floatingTabBar` 字段。

- **手机竖屏**：页面与信息流可在胶囊栏后方继续绘制；列表底部额外提供足够滚动距离，保证最后一条内容也能完整移到导航栏上方。发布动态和更新按钮主动避让悬浮栏。
- **输入键盘时**：隐藏底部导航（悬浮版与经典版），为评论、搜索或私信输入留出空间；收起键盘自动恢复。
- **横屏与宽度 ≥600dp 的大屏设备**：采用 `NavigationRail`，包括竖屏平板，避免巨大的底部胶囊栏。
- **中尺寸屏幕**：浮动栏最大宽度为 420dp，居中对齐，并按无障碍文字缩放调整高度。
- **首页顶部的“应用、动态、热门”等标签**：不受影响。
- **重复点击主页／关注入口的返回顶部动作**：沿用原来的控制器，不改变事件逻辑。
- **账号切换**：仍然清理旧账号页面和路由；仅改变导航容器，不另建账号状态。
- **字体放大**：根据系统字号缩放适当增加导航栏高度，避免标签受挤压。

它是 Flutter 应用内部的页面组件，**不会在其他应用上层显示，也不需要 Android 悬浮窗权限**。不开启新权限、不读取个人数据，也不增加网络请求。

## 实现

- `lib/components/floating_tab_bar.dart`：纯 Flutter Material 3 导航栏，圆角、投影、图标/文案、可访问性。
- `lib/pages/main/main_page.dart`：监听 Hive 的 `SettingsBoxKey.floatingTabBar`，即时切换并保留 PageView 的控制器及选中页。
- `lib/pages/settings/settings_page.dart`：开关入口。

## 自动化检查

- 开关默认值、持久化与独立性。
- 竖屏动态启用／关闭，切换主页、关注、我的时选中状态正确。
- 旋转横屏仍使用导航侧栏，回到竖屏恢复悬浮栏。
- Root PageView 保持全高；消息页、动态列表、应用列表、话题列表和首页卡片的滚动范围提供额外底部间距，悬浮栏下方内容可以滚动至可读区域。
- FAB 避开胶囊导航，避免“发布动态”与“更新应用”操作按钮重叠。
- 输入法弹出时导航自动隐藏、恢复；竖屏平板宽度达到 600dp 即显示导航侧栏。
- Flutter 带真实思源黑体的合成视觉预览图 `build/review/floating-tab.png`。
- 用户之前的字体、账号、离线回归测试全部必须继续通过。

自动化仅代表代码行为正常；实际设备仍需复查不同 Android 系统手势条、三键导航、折叠屏、横屏和无障碍大字号。悬浮栏只占用必要的命中区域，不会申请系统悬浮窗权限。
